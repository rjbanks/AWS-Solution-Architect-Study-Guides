# AWS SAA-C03 Pocket Guides

A lightweight, independent reference library for the AWS Solutions Architect Associate exam. 16 guides, original scenario quizzes, conceptual flow diagrams, Route 53 simulations, search, dark mode and printable notes. No dependencies or build steps.

## Open locally

Open `index.html` in a browser. Browser storage saves reviewed status and theme when available. Quiz results reset on reload.

## Publish with GitHub Pages

1. Create a new public repository named `aws-saa-pocket-guides`.
2. Upload `index.html`, `README.md` and `.nojekyll` to the root of the `main` branch. The HTML is self-contained; `guide-data.txt` is optional reference content.
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
4. Open the URL shown under Pages after deployment.

See https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site.

## Scope

Study notes, not an exhaustive exam course or official AWS materials. Architecture flows are schematic. Exam priorities are editorial, not guaranteed exam coverage. AWS services evolve; follow the official documentation links in each guide.
